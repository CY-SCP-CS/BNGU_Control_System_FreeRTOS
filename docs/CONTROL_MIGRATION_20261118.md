# 控制修复与裸机逻辑移植（2026-11-18）

来源：`D:/STM32project/BNGU_Control_System`。目标：`D:/STM32project/BNGU_Control_System_FreeRTOS`。

本轮对比了 2026-11-05 保存的裸机参考与当前来源工程，按行为移植新增逻辑。RTOS 保持单一硬件拥有者、任务间值对象和快照、纯算法与端口隔离；不复制裸机主循环和中断调度。

## 已修复的控制问题

- 控制源变化时，云台对齐实际姿态、复位 PID、停火；切入 CAN 丢弃切换当周期更新，等待新帧授权，避免沿用 DBUS 发射状态。
- 功率缩放不再使用增益、输出限幅均为零的空 PID。实测功率高于固定 100 W 目标时，以 `sqrt(target / measured)` 降低统一电流缩放，恢复速率限制为每毫秒 0.001。这是保守反馈缩放，不能保证任意工况的瞬时功率不超过目标，仍需实车验证和调参。
- 云台在读取快照后、整理完命令后分别取得当前时间；队列过滤使用实时读取时间，避免抢占后新样本比周期时间更晚而被误判过期。底盘也在读取命令后取得决策时间。
- IMU 芯片 ID 不匹配的样本在 AHRS 更新之前被拒绝，并发布无效状态、重置滤波历史。控制同时要求运行采样、设备有效和滤波就绪。异常长采样间隔恢复也重建滤波历史。
- Pitch 启动和恢复对齐当前角度，不再固定回零。恢复前要求反馈持续有效 20 ms。
- 同周期同 ID 角度增量累加；绝对角度采用最后到达的 0x123/0x127 类型。跨类型优先级保持来源工程约定：增量先应用，绝对角度随后覆盖，显式发射命令最后裁决。
- CAN 连续控制输出按类型保存最新值；编码直接按总线/ID 更新待发槽，删除原控制 FIFO 和两个 TX FIFO。电流超过 20 ms 转为零；底盘速度超过 100 ms 转为急停。提交硬件邮箱前再次检查时间。硬件已接受的邮箱帧不在这一层撤回，故障总线仍需实测。
- 超时停火只是禁止输出，不伪装成 0x129 命令；因此不会永久阻止后续 0x127 的发射请求。显式 0x129 的覆盖优先级保持到切换控制源或复位。

| Pitch 加速度前馈 | IMU 发布安装补偿后的机体系加速度，Pitch 使用慢基线、动态低通、软死区和限幅；参数沿用来源 |

## 有意保留的 RTOS 适配

来源工程默认板型、裸机 UART 回调、定时器中断驱动控制、全局裁判数据和关中断复制没有覆盖到 RTOS。板型仍由 CMake 预设决定；收发及解析仍由所属任务管理。来源的手柄 VOFA 直发没有进入控制算法，沿用集中日志/遥测接口，避免抢占 UART1 TX。

来源 `app_init` 取消磁力计初始化没有照搬：RTOS 已有独立磁力计诊断和测试，不应随裸机主循环改动删除。IMU 采样/标定节拍仍由 RTOS 端口负责，新增算法查询和输出接口已移植。

移除了全零车体 x/y/w PID 及无效力/力矩分配调用，轮级速度和舵角闭环仍保留。底盘急停复位不再重复装载全部参数；清理旧 DBUS→Shoot 命名和不符合实现的注释。SI/legacy 数值适配仍保留，以免未经单位重算直接改变现有控制增益；后续可按机构逐步迁移。
